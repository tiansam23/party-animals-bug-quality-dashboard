# Party Animals Bug Quality Dashboard V1

React + TypeScript + Vite + Apache ECharts + Tailwind CSS。纯前端、飞书视图本地快照，不包含网页登录、后端、数据库或全局筛选器。

顶部使用《猛兽派对》官网提供的 Nemo 游戏图标，并作为本地静态资源加载。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

访问终端显示的本地地址（默认 http://127.0.0.1:5173）。

```bash
npm test       # 历史状态与统计一致性测试
npm run build # TypeScript 检查和生产构建
npm run preview # 本地预览 dist 产物
```

## 目录与数据替换

- `src/data/model.ts`：Bug、StatusEvent、BugSource 数据契约；历史快照、趋势、摘要和分布计算。
- `src/data/mock.ts`：固定种子的统一模拟数据；包含 480 条期初积压记录与 60 天的新增和状态变更。
- `src/components/Chart.tsx`：ECharts 生命周期与 ResizeObserver 自适应封装。
- `src/App.tsx`：看板组件与独立的模块/优先级视角切换。
- `src/styles.css`：共享 CSS Grid 轨道和响应式布局；Tailwind 由 Vite 插件编译。

当前适配器为 `src/data/source.ts`。替换 Excel/CSV 或 API 时，实现 `BugSource.load(): Promise<Bug[]>` 并替换 App 中的数据源即可。导入层需把外部字段映射到 Bug 契约，保证唯一 ID、合法状态、完整且按时间排序的状态历史；只有当前状态无法准确重建历史趋势。日期为 ISO 8601 UTC，模拟日界线以 UTC 为准。生产导入可统一转换到所选业务时区后再计算。

## 原始演示数据统计口径（仅测试夹具）

周期：2025-08-01 至 2025-09-29，共 60 天。期初存量取 08-01 00:00 之前的快照；期末取 09-29 日末快照。

- 有效 Bug：排除“不处理”。未关闭：排除“已关闭”和“不处理”。
- 每日新增：当天创建的全部 Bug 数；每日关闭：当天进入“已关闭”的状态变更次数。
- 每日已解决：按北京时间统计当天新进入“已解决”或“主线测试中”的 Bug；同一 Bug 同一天去重计 1 条，使用左侧每日数量轴，以紫色折线显示。跨日重新进入可在新的一天计数。仅关闭或进入“已修复”不会计入该指标。
- 未关闭趋势：逐条回放截至当日日末的实际状态，包含重新打开、转为不处理、从不处理恢复。
- 模块/优先级分布：默认统计期末全部有效 Bug，独立切换到期末未关闭 Bug。
- 状态分布：排除“不处理”；“主线测试中”和“已修复”合并展示为“已修复”。
- 未关闭 Bug 存量：取选中结束日的快照，下方显示与最新数据日的前一自然日日末相比的变化；不受主图缩放或图例选择影响。
- 各优先级在本次模拟中固定，不模拟优先级变更。所有图表来自同一数据集，无单独随机指标。

## 布局与交互

桌面使用 4 列 × 12 行共享网格，列比例为 `1 : 1 : .68 : .68`，主图跨前两列及前八行；右侧与底部严格共用网格边界。1920×1080 为主要适配目标；950px 以下两列，600px 以下单列。主图支持 tooltip、图例显隐；时间缩放仅通过下方滑块操作，关闭图内滚轮、双指及拖拽手势缩放。

右上角时间过滤器支持自定义起止日期、最近 7 天、最近 14 天和全部范围。默认开启“隐藏无数据日”，仅压缩趋势图中的空白日期；所有分布和 KPI 统一按所选结束日快照计算，“较昨日变化”使用最新数据日的存量与其前一自然日日末存量比较。

刷新真实数据（需本机安装 Meegle CLI 并已授权）：

```bash
meegle auth login --device-code --host project.feishu.cn
npm run sync:feishu
npm test
npm run build
```

同步脚本会读取字段元数据、完整视图分页，以及全部记录的状态/优先级历史；读取失败或校验不一致时不会覆盖上一份快照。图表和 KPI 的数据仍共用统一数据源。
